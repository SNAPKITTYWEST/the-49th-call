## AMBIGUITY IDENTIFICATION & RESOLUTION

### IDENTIFIED AMBIGUITY 1: Emphatic vs. Non-Emphatic /t/
**Issue**: Aramaic distinguishes emphatic ṯ (pharyngealized) from non-emphatic t.
- Transliteration: ṯ (emphatic alveolar) vs. t (plain alveolar)
- **Resolution**: Context and morphological template disambiguate:
  - qal stems: emphatic ṯ in certain templates (e.g., CəCaC)
  - Passive stems: some shifts occur
  - **For √KTB**: emphatic ṯ is standard in qal forms; unambiguous

### IDENTIFIED AMBIGUITY 2: Determined State Marker
**Issue**: The suffix -ā in kāṯəḇā could be interpreted as:
  a) Determined/emphatic marker (most likely)
  b) Feminine singular (unlikely, given masculine context)
  c) Construct state prefix (unlikely, not how Aramaic works)
- **Resolution**: Morphological context (masculine singular, agent noun) confirms (a)
- **For kāṯəḇā**: determined masculine singular agent — unambiguous

### IDENTIFIED AMBIGUITY 3: Prefix yi- vs. other 3sg markers
**Issue**: Aramaic has multiple conjugation systems; yi- marks qal imperfective.
- **Resolution**: Vocalic template yi-CiCuC confirms qal; other stems would differ
- **For yikhtuḇ**: unambiguous qal imperfective
